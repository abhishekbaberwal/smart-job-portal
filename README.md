\# Smart Job Portal



\## Project Overview



Smart Job Portal is a web-based job portal developed as an FSD project. The application provides users with a simple and responsive interface to explore job opportunities and access user-oriented pages.



\## Features



\- Home page

\- Job listings page

\- User login page

\- User registration page

\- Responsive web design

\- Simple and user-friendly interface



\## Technologies Used



\- HTML5

\- CSS3

\- JavaScript
